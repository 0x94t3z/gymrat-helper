# Gymrat Helper 🏋️

Gymrat Helper is an instruction-based AI skill that converts gym and diet notes
into structured training analysis and clear next actions.

This is **not an app** and **not a CLI tool**.

---

## What this is

- A reusable instruction set
- Designed for ChatGPT
- Distributed via Molthub
- Focused on sustainable fitness guidance

---

## How to use

1. Open `SKILL.md`
2. Copy all contents
3. Paste into ChatGPT
4. Paste your gym notes
5. Ask the AI to apply the rules
